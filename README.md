# Catálogo de Filmes

Projeto desenvolvido para a Unidade I, utilizando tecnologias web básicas como **HTML**, **CSS** e **JavaScript**.

## Descrição

Este projeto consiste em uma aplicação/site web estruturado com páginas HTML, estilos CSS e scripts JavaScript. O objetivo é aplicar conceitos fundamentais de desenvolvimento front-end, como estruturação de páginas, estilização visual e interatividade com o usuário.

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do Projeto

```text
.
├── css/
│   └── style.css
├── js/
│   └── script.js
├── pages/
│   └── argumentos.js
├── index.html
└── README.md
```

## Como Executar o Projeto

1. Clone ou baixe este repositório:

```bash
git clone https://github.com/ariel-marquess/catalogo-de-filmes.git
```

2. Acesse a pasta do projeto:

```bash
cd catalogo-de-filmes
```

3. Abra o arquivo `index.html` em um navegador de sua preferência.

Também é possível abrir o projeto diretamente em um editor como **Visual Studio Code**, **WebStorm** ou outro ambiente de desenvolvimento.

## Estilos

Os arquivos CSS ficam armazenados na pasta:

```bash
css/
```

Essa pasta contém os estilos responsáveis pela aparência visual das páginas.

## Scripts

Os arquivos JavaScript ficam armazenados na pasta:
